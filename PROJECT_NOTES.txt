5. ইনস্টল সমস্যা ও stable signing key (গুরুত্বপূর্ণ)
------------------------------------------------------
কারণ: প্রতিটি CI build-এ অস্থায়ী debug key ব্যবহার হতো, তাই signature বদলে যেত এবং
আগের install-এর উপর update হতো না। সমাধান: একটি স্থায়ী keystore তৈরি করে GitHub Secrets-এ রাখা।

GitHub Secrets (repo Settings > Secrets and variables > Actions):
- RAS_KEYSTORE_BASE64   : keystore ফাইলের base64 রূপ
- RAS_KEYSTORE_PASSWORD : keystore password
- RAS_KEY_ALIAS         : key alias
- RAS_KEY_PASSWORD      : key password

সতর্কতা:
- Keystore ফাইল ও password নিরাপদ জায়গায় ব্যাকআপ রাখুন। হারালে পরে আর update করা যাবে না।
- এই ফাইলে বা repo-তে কখনো keystore বা password commit করবেন না।
- একবার পুরোনো (debug key দিয়ে) install মুছে নতুন install করতে হতে পারে;
  এতে অ্যাপের ভিতরের downloads ও app data মুছে যাবে।
- Secrets না থাকলে workflow এখনও debug key ব্যবহার করবে, তাই পরবর্তী update-এর আগে secrets সেট করা জরুরি।

6. Versioning
-------------
প্রতিটি CI build-এ versionCode = build number এবং versionName = 1.0.<run number>.
এতে পুরোনো install-এর উপর নতুন APK update হতে পারে (signature একই থাকলে)।
